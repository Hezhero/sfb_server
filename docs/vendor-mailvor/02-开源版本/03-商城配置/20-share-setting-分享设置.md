# 分享设置

### 1. 自建网站

- 上传压缩文件share.zip到服务器的网站目录（网站自行搭建），记住shareapp.html和sharegoods.html的地址 ![img.png](https://www.mailvor.com/opensource/setting/img/share/img.png)
- 设置app分享地址和商品分享地址，打开管理后台“会员管理”->“会员”->“APP基础信息配置” ，设置app分享地址（shareapp.html的地址）和商品分享地址（sharegoods.html的地址） ![img_1.png](https://www.mailvor.com/opensource/setting/img/share/img_1.png)
- 修改网站内容，shareapp.html和sharegoods.html中的js、image、css、包名等路径修改成域名全路径 ![img_2.png](https://www.mailvor.com/opensource/setting/img/share/img_2.png)

### 2. 快站

- 需要快站尊享版，并且把站点改成“极速版”
- 修改shareapp.html和sharegoods.html中的js、image、css、包名等路径
- 新建快站页面app分享，拷贝shareapp.html中header的内容到快站的“头部组件”，body的内容到快站的“HTML/JS组件”，保存发布
- 新建快站页面商品分享，拷贝sharegoods.html中header的内容到快站的“头部组件”，body的内容到快站的“HTML/JS组件”，保存发布 ![img_3.png](https://www.mailvor.com/opensource/setting/img/share/img_3.png)
- 复制快站地址，参照自建网站设置app分享地址和商品分享地址
