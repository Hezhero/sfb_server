# 13 · 第三方账号梳理（微信 / 极光 / 蒲公英）

> 调研日期：2026-11-18 · 结论：微信与极光是业务必需且与原作者主体绑定，改包名后必须整体重配；蒲公英只是文案链接，风险最低。

## 总览

| 类别 | 业务必需 | 不换的后果 | 风险 |
|---|---|---|---|
| 微信 | 是（登录/支付/分享/公众号/客服） | 改包名后微信登录 `errcode -1`；全链路依赖作者开放平台主体 | **高** |
| 极光 JPush | 是（推送） | 所有设备注册在作者极光应用下，作者可向你全部用户推任意消息 | **高** |
| 蒲公英 | 否（仅公众号文案下载链接） | 用户被引导到作者蒲公英应用下载，品牌与分发权归作者 | 中 |

## 一、微信

### 配置项（真实值在 APP 端未打码）

| 项 | 位置 |
|---|---|
| 开放平台 AppID | `app/lib/util/global.dart:90`（`wx139d763ebb9a29e0`）、`Info.plist:25,36` |
| Universal Link | `global.dart:91`、`Runner.entitlements:13` |
| 企业微信客服 kfid/CorpID | `global.dart:96-98` |
| 服务端 AppID/Secret | `mshop-app`、`mshop-admin` 各 `application-prod.yml:187-190`（dev 同步） |
| 公众号/小程序凭据 | 存 Redis，`SystemConfigConstants.java:37,44-47`；后台配置页 `admin/src/views/wechat/config/index.vue`、`wxapp.vue` |
| 微信支付 | `admin/src/views/shop/payset/PayCertificateEditor.vue`（appId/mchId/mchKey/证书，存 DB） |

### 用途

APP 登录（`fluwx.registerApi`/`authBy`）、公众号 H5 登录、微信绑定（提现授权）、微信支付（App/公众号/小程序/H5/Native）、分享、公众号菜单/消息/模板消息、小程序订阅/直播、企业微信客服。

### 替换清单

1. APP 4 处：`global.dart:90-91`、`Info.plist:25,36`、`Runner.entitlements:13`
2. Server 两份 prod.yml（+ dev）：`wx.app.appId/secret`
3. 后台改数据（不改代码）：公众号/小程序/支付配置页
4. 企业微信客服：`global.dart:96-98`
5. 微信开放平台重建应用（**AppID 与包名+签名指纹绑定**，企业认证 300 元/年）、公众号服务器配置、支付商户签约

> `admin/.../wechat/config/pay.vue` 是已废弃的历史页面，无需改。

## 二、极光 JPush

| 项 | 位置 |
|---|---|
| AppKey（Dart） | `app/lib/util/global.dart:94`（`f4b96adeec4eb2a41d831551`） |
| AppKey（Android 原生） | `app/android/app/build.gradle:46`（必须与 Dart 一致） |
| MasterSecret | `mshop-app`、`mshop-admin` 的 `application-prod.yml:148-149/:158-159` |

用途：推送初始化、按 uid 设 alias 定向推、注销删 alias；服务端 `JPushService.java` 调 `api.jpush.cn/v3/push`。业务推送点覆盖提现通知、新订单、分销升级等，均业务必需。

替换清单：APP **两处同步** + Server 两份配置 + 极光控制台新建应用（**AppKey 与包名绑定**）+ 隐私政策披露与授权弹窗。

**不换的后果**：原作者持有 Master Secret 可向你的全部用户推任意通知（钓鱼/伪造账户异常），是直接攻击面。

## 三、蒲公英

真正的蒲公英痕迹只有 3 处，且都是公众号自动回复文案里的下载链接：
- `server/mshop-mp/.../MenuHandler.java:48`
- `MsgHandler.java:70`、`:89`（现为 `https://www.pgyer.com/sanyinghui`）

APP 更新地址从 server `/updateConfig` 动态取，存 DB（`admin/src/views/shop/appVersion/index.vue`），非硬编码。

> `app/package/maixs_utils/lib/config/net/pgyer_api.dart` 只是命名误导的通用 HTTP + AES 工具，无蒲公英 SDK、无 pgyer.com 请求，可不改。

替换清单：改 3 处文案链接 + 后台 appVersion 的 iosUrl/androidUrl；可选注册自有蒲公英账号。

## 四、最小可用替换清单（按优先级）

| 序 | 操作 | 位置 |
|---|---|---|
| 1 | 换极光 AppKey（两处同步） | `global.dart:94` + `build.gradle:46` |
| 2 | 换极光 MasterSecret | 两份 prod.yml |
| 3 | 换微信开放平台 AppID（3 处联动） | `global.dart:90`、`Info.plist:25,36`、两份 prod.yml |
| 4 | 换 Universal Link + Associated Domain | `global.dart:91`、`Runner.entitlements:13` |
| 5 | 后台改公众号/小程序/支付配置（改数据） | admin 配置页 |
| 6 | 换企微客服 kfid/CorpID | `global.dart:96-98` |
| 7 | 改 3 处蒲公英下载链接文案 | `MenuHandler.java:48`、`MsgHandler.java:70,89` |
| 8 | 各平台控制台重建应用/签约 | 微信开放平台、公众号、支付、企微、极光 |

**关键联动**：微信 AppID 与包名+签名指纹绑定，极光 AppKey 与包名绑定——必须「一次改全」，改一半会导致登录 `errcode -1`、极光推空。预留 3~5 个工作日平台审核。
