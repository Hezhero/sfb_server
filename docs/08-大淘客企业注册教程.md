# 大淘客企业注册与 API 接入教程

> 编写时间：2026-11-13
> 适用：用**营业执照**（公司或个体工商户）注册大淘客，并接入本项目
> 说明：平台页面会改版，具体按钮位置以你实际看到的为准，流程框架不会变

## 官网实测结论（2026-11-13 实际访问 dataoke.com）

| 结论 | 依据 |
| --- | --- |
| 注册页**没有**"个人/企业"选项，先注册普通账号 | 实测注册页只有手机号+验证码、微信扫码 |
| 开发者入口不在 `open.dataoke.com`，在 `/kfpt/` | 旧域名访问报"该域名未关联 CMS 服务" |
| 「成为开发者」是 JS 弹层，登录后才跳 `/kfpt/api-reg.html` | 按钮 `onclick="new $layerLogin({jumpUrl:'/kfpt/api-reg.html'})"` |
| 企业资质在**登录后**才提交 | `/kfpt/api-reg.html` 未登录会跳回 `/login` |
| 官网导航叫「爆品物料API」，不叫"开放平台" | 首页导航实测 |

**所以正确顺序是**：注册普通账号 → 登录 → 爆品物料API → 成为开发者 → 填企业资质。

## 一、先准备这些材料

| 材料 | 要求 | 备注 |
| --- | --- | --- |
| 营业执照 | 三证合一彩色扫描件/清晰照片 | 不能模糊、不能反光、不能只拍一半 |
| 法定代表人身份证 | 正反面彩色 | 与执照上的法人一致 |
| 对公账户信息 | 开户行、账号 | 企业认证用，个体户可绑经营者同名储蓄卡 |
| 手机号 | 国内运营商实名号 | **不能用 170/171 等虚拟号段**，会直接驳回 |
| 常用邮箱 | 能收验证码 | — |
| 申请确认书 | 大淘客提供模板，需**亲笔签字 + 加盖公章** | 个体户没有公章的，按页面提示处理 |
| 渠道证明 | 至少 2 张：联盟后台订单截图、微信群/公众号后台、APP 截图等 | 不打码，能看出真实流量 |

**经营范围有要求**：营业执照经营范围需包含电子商务、计算机、互联网、网络技术研发、网上贸易代理、经营广告业务等中的至少一类。纯餐饮、纯零售的执照可能被拒。

## 二、第一步：注册账号

**入口**：<https://www.dataoke.com/login/?user=reg>

两种方式，都不需要填企业信息：

| 方式 | 说明 |
| --- | --- |
| 手机号 + 验证码 | 输入手机号 → 获取验证码 → 设置密码 |
| 微信扫码 | 扫码关注公众号即完成注册 |

> **重要**：官网注册页**没有"个人/企业"选项**。注册出来的是普通账号，企业资质在后面的「成为开发者」环节才提交。别在注册页找企业入口，找不到是正常的。

> ⚠️ **一张身份证只能申请一个"团队"类型账号**；企业类型账号按营业执照算，**同一执照最多认证 3 个**。
> 如果你打算给 admin 和 app 各开一个，必须走**企业**类型。

---

## 三、第二步：企业实名认证（关键一步）

登录后进入账号设置完成实名。具体路径随版本变化，通常在「个人中心 → 实名认证」或「账号管理 → 资质认证」。

1. 选择主体类型：**企业**

> ⚠️ 个体工商户注意：官方规则写「**个体工商户不得入驻企业账号，需选择团队入驻**」。个体户请选「团队」，上传执照但仍按团队流程走，拿不到企业的 3 个账号额度。

2. 上传营业执照扫描件
3. 填写企业信息（必须与执照完全一致）：
   - 企业名称：一字不差，包括括号（中文括号，不是英文括号）
   - 统一社会信用代码：18 位，注意 `0` 和 `O`、`1` 和 `I`
   - **注册地址**：填执照上的「住所」栏，不是你现在的办公地址
   - 法定代表人姓名、身份证号
4. 上传法人身份证正反面
5. 填写对公账户信息
6. 提交，等审核

**审核周期**：主体资质约 24 小时（工作日），完整认证 1-3 个工作日

**常见驳回原因**（按出现频率）：

| 原因 | 怎么避免 |
| --- | --- |
| 证件照模糊/反光/缺角 | 白天自然光拍，四个角都要拍到 |
| 手机号未实名或虚拟号段 | 用本人实名的主号 |
| 企业名称括号用了英文 | 执照上是（）就填（），不能填() |
| 经营范围不符 | 见上面"经营范围有要求" |
| 同一执照重复提交 | 提交前确认没有进行中的申请 |
| 公司被列入经营异常名录 | 先在国家企业信用信息公示系统查明状态 |

## 四、第三步：成为开发者（真正的入口在这）

**官网版式**：首页导航「爆品物料API」→ 进入开放平台 → 点右上角「成为开发者」

**直达链接**（2026-11 实测有效）：

| 页面 | URL |
| --- | --- |
| 开放平台首页 | <https://www.dataoke.com/kfpt/openapi.html> |
| API 市场 | <https://www.dataoke.com/kfpt/api-market.html> |
| **开发者注册** | `https://www.dataoke.com/kfpt/api-reg.html`（**必须先登录**，否则跳回登录页） |
| API 文档示例 | `https://www.dataoke.com/kfpt/api-d.html?id=7` |

**操作顺序**：

1. 先在 <https://www.dataoke.com/login/?user=reg> 注册并登录
2. 打开 <https://www.dataoke.com/kfpt/openapi.html>
3. 点右上角「成为开发者」
4. 页面会跳到 `/kfpt/api-reg.html` 填写开发者资质

> ⚠️ **踩坑提醒**：网上很多教程（包括 AI 生成的）写的开发者入口是 `open.dataoke.com`，**这个域名现在已经打不开了**，访问会显示"该域名未关联 CMS 服务"。别在那儿浪费时间，真实入口是 `www.dataoke.com/kfpt/`。

> ⚠️ 「成为开发者」这个按钮是 JS 触发的（`onclick` 弹登录层），不是普通链接，**右键复制链接拿不到地址**。必须登录后点。

## 五、第四步：创建应用，拿 AppKey / AppSecret

**路径**：开放平台 → 我的应用 → 创建应用

填写内容：

| 字段 | 怎么填 | 注意 |
| --- | --- | --- |
| 应用名称 | 含公司简称，如「XX科技返利系统」 | 别用"采集""爬虫""破解"字样 |
| 应用类型 | APP / 网站 / 小程序，按你的载体选 | 选错会影响后续权限 |
| 应用描述 | **这一栏决定审核通过率** | 见下方模板 |
| 回调域名 | 填已备案的 HTTPS 域名 | 未备案域名后续调用会报 `invalid-domain` |

**应用描述模板**（照抄改改，比"用于开发测试"通过率高得多）：

> 用于自营导购 APP「XX」的商品同步与订单追踪。通过商品查询接口按关键词/类目获取商品列表，展示券后价与优惠券信息；通过高效转链接口生成推广链接供用户分享；通过订单接口同步成交订单用于返佣结算。
> 已绑定淘宝联盟推广位 PID：`mm_xxx_xxx_xxx`。
> 日调用量预估 5000 次，峰值 QPS 3。APP 已上线：<应用市场链接>。

提交后通常 2-5 小时出结果。通过后在「我的应用」里能看到 **AppKey** 和 **AppSecret**。

> ⚠️ **AppSecret 只显示一次**，复制后立刻存到密码管理器，别截图、别贴在网页编辑器里。

## 六、第五步：逐个申请接口权限

**路径**：应用详情 → API 市场

按这个顺序申请，不要一次全勾：

| 顺序 | 接口 | 开通条件 |
| --- | --- | --- |
| 1 | 商品查询 `dataoke.items.get` | 即时开通 |
| 2 | 高效转链 `dataoke.links.convert` | 即时开通，**但它是订单接口的前置** |
| 3 | 订单查询 `dataoke.orders.get` | **需连续 3 天调用高效转链接口后才可申请** |

第 3 条意味着：**注册完当天拿不到订单接口**。这三天里把转链接口跑起来（哪怕用测试脚本），第 4 天再申请订单权限。

> 这条来自实操文档，官方文档没写死，以你后台显示的提示为准。

---

## 七、第六步：填进项目配置

两份 yml 都要填（`mshop-admin` 和 `mshop-app` 各一份）：

```yaml
dataoke:
  key: 你的AppKey
  secret: 你的AppSecret
```

**如果开了两个账号**（企业执照最多 3 个）：

```yaml
# mshop-admin（订单采集，耗配额）
dataoke:
  key: 账号A的AppKey
  secret: 账号A的AppSecret

# mshop-app（客户端查询，高频）
dataoke:
  key: 账号B的AppKey
  secret: 账号B的AppSecret
```

原项目注释就建议这么分：

> `# todo 大淘客开放平台key和密钥，最好和mshop-app中的不一致，防止订单采集耗空调用量`

## 八、注册完还要做的两件事（容易漏）

### 8.1 绑定淘宝联盟 PID

大淘客只是接口通道，**佣金要进你自己的淘宝联盟账户**，所以必须把淘宝联盟的 PID 配进大淘客：

开放平台 → 统一授权中心 → 配置 PID

不绑定的后果：转链能成功，但订单归因不到你，佣金进不了你的账户。

### 8.2 确认调用配额

开放平台 → 应用详情 → 查看当前 QPS 和日调用量上限。

订单采集是定时任务，耗配额最凶。如果配额不够，把采集频率调低（项目里 `{"minutes": 10}` 改成 30）。

## 九、时间线参考

```
第 1 天上午   手机号注册 + 企业实名提交
第 1 天下午   实名通过（24h 内）
第 2 天       开发者入驻提交 → 当天或次日通过
第 2-3 天     创建应用 → 2-5 小时出结果
第 3 天       申请商品 + 转链接口（即时开通）
第 3-6 天     连续调用转链接口 3 天
第 6 天       申请订单接口
第 6 天       填进 yml，跑通
```

**顺利的话 6 天，卡在资质上可能 2 周。**

## 十、常见问题

**Q：个体工商户能不能注册？**
能。但按官方规则**不能选"企业"类型**，要选「团队」。个体户能拿到 API 权限，只是没有"同一执照 3 个账号"的额度。

**Q：营业执照刚下来，能注册吗？**
部分平台对新执照有 14 天限制（工商数据同步延迟）。大淘客没明确写，但如果提示"信息核验失败"，等几天再试。

**Q：审核被拒了怎么办？**
看驳回理由，补齐材料重新提交。被拒不是拉黑，次数没有硬性限制，但反复提交相同材料会拉长审核时间。

**Q：能不能先不绑淘宝联盟 PID？**
技术上可以拿到 key，但转链后佣金归不到你，等于白干。**PID 绑定是必做项**。

**Q：企业认证和个人认证，能拿到一样的接口吗？**
接口能力一样，差别在账号数量、配额等级和结算主体。返利类业务建议用企业主体，个人主体有被拒的风险。
