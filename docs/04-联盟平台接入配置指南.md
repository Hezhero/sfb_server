# 联盟平台接入配置指南（淘宝 / 京东 / 唯品会 / 穿山甲）

> 适用：本地或生产环境部署完成后，接入电商联盟与广告平台
> 依据：`sfb_server` 源码实测（配置类 `TbConfig` / `JdConfig` / `DataokeConfig`）

---

## 先说结论：这些配置不在后台页面

你现在打开的 `http://localhost:8013/dashboard` 是运营管理后台，管的是商品、订单、用户、活动。

**四个平台的 API 凭据全部写在服务端 yml 里，后台没有任何页面可以改它们。** 全项目搜索 `com.junchen.constant.SystemConfigConstants`（数据库配置表 `system_config` 的常量定义），里面只有 API 地址、微信、提现、返利比例这些，**没有淘宝/京东/唯品会的 AppKey**。

所以别在后台里找了，直接改配置文件。

---

## 配置位置速查

两个应用各有一份配置，**都要改**：

```
server/mshop-admin/src/main/resources/config/application-dev.yml   ← 后台/订单采集
server/mshop-app/src/main/resources/config/application-dev.yml     ← APP 客户端接口
```

> ⚠️ 你现在跑的是 **dev** profile（`application.yml` 里 `spring.profiles.active: dev`），所以改 `application-dev.yml`。改 `application-prod.yml` 不会生效。
> 生产环境则相反。**两份文件内容结构一样，行号也一致**，按下面表格对号入座即可。

| 平台 | 配置前缀 | admin 行号 | app 行号 | 参数个数 |
| --- | --- | --- | --- | --- |
| 大淘客（含唯品会/抖音） | `dataoke:` | 100-104 | 92-94 | 2 |
| 淘宝联盟 | `tb:` | 142-152 | 133-143 | 6 |
| 京东联盟 | `jd:` | 159-166 | 149-156 | 6（其中 1 个无效） |
| 拼多多 | `pdd:` | 137-140 | 128-131 | 3 |
| 唯品会 | — | — | — | **无独立配置** |
| 穿山甲 | — | — | — | **未集成** |

## 一、淘宝联盟

### 需要填的 6 项（admin 第 142-152 行 / app 第 133-143 行）

```yaml
tb:
  appKey: xxxx3230                                              # 淘宝开放平台应用的 AppKey
  appSecret: xxxxxxe76575eddfeebxxxxxx8f0f2d2                   # 对应 AppSecret
  url: https://eco.taobao.com/router/rest                       # 网关地址，不要改
  inviterCode: XSJL93                                           # 渠道邀请码，见下方说明
  pid:
    channelPid: mm_52650383_39582271_114587650437               # 渠道推广位 PID
    tljPid: mm_52650383_3088500089_115682150104                 # 淘礼金推广位 PID
```

### 参数从哪来

| 参数 | 来源 | 说明 |
| --- | --- | --- |
| `appKey` / `appSecret` | **淘宝开放平台** <https://open.taobao.com> | 创建应用后申请「淘宝客」API 权限。**注意不是联盟后台的账号密码**，必须是开放平台应用的 AppKey |
| `channelPid` | **淘宝联盟后台** <https://pub.alimama.com> → 推广管理 → 推广位 | 格式必须是 `mm_数字_数字_数字` |
| `tljPid` | 同上，另建一个推广位专用于淘礼金 | 官方建议和渠道 PID 分开，便于对账 |
| `inviterCode` | 联盟后台 → 渠道管理 → 渠道邀请码 | 用于渠道备案（`UserController:337` 会把它传给淘宝做渠道关系绑定）。不走渠道模式可留空 |
| `url` | 固定值 | 不要改 |

### 代码怎么用这些参数

- `TbConfig.getAdZoneIds()` 会取两个 PID 的**最后一段数字**（`mm_52650383_39582271_114587650437` → `114587650437`），订单采集时用它过滤。
- `TbConfig.getAdZoneId()` 取的是 `tljPid` 的最后一段，用于判断订单是否为淘礼金订单。

**这意味着 PID 填错或者漏填，订单会被静默过滤掉**——表现是"转链正常，但一条订单都采不到"。

### 转链用的接口

`TkService` 里调用的是 `taobao.tbk.*` 系列（如 `TbkDgVegasTljCreateRequest` 创建淘礼金）。这要求在开放平台申请到淘宝客权限，**新建应用默认没有，需要提交审核**。

## 二、京东联盟

### 需要填的 6 项（admin 第 159-166 行 / app 第 149-156 行）

```yaml
jd:
  appKey: xxxxxx4a54919f7e5axxxxxx8436301       # 京东联盟开放平台 AppKey
  appSecret: xxxxxxc5a8bc432682xxxxxxe638cb06    # 对应 AppSecret
  server: https://api.jd.com/routerjson          # 网关，不要改
  siteId: 41xxxxxx62                             # 网站/APP 推广位 ID
  unionId: 10xxxxxx54                            # 联盟 ID
  key: e420xxxxxxb9f8e29ebdee4bfd747b07...       # ⚠️ 无效配置，见下
```

### 参数从哪来

| 参数 | 来源 | 说明 |
| --- | --- | --- |
| `appKey` / `appSecret` | **京东联盟开放平台** <https://union.jd.com> → 开放平台 → 应用管理 | 需完成联盟实名认证 |
| `siteId` | 联盟后台 → 推广管理 → 网站/APP 管理 | 创建媒体后获得，是**推广位**的 ID |
| `unionId` | 联盟后台 → 我的联盟 | 账号级的联盟 ID |
| `key` | — | **代码里没有使用点**（已确认：`JdConfig.key` 只有声明，全项目无 `getKey()` 调用）。留空即可，不影响功能 |

### 转链用的接口

`JdService.goodsWordUnion()` 用的是 `UnionOpenPromotionCommonGetRequest`（京东联盟「获取推广商品信息」接口），需要 AppKey 对应的应用有该接口权限。

代码里还按 `siteId` 做了订单过滤（`OrderTask.saveJd()`），所以 siteId 填错同样会"转链正常、订单为空"。

## 三、唯品会（不需要单独配置）

**唯品会在本项目里没有独立配置项**，全部走大淘客中转。已确认三处：

| 功能 | 实现 |
| --- | --- |
| 商品列表/详情/搜索 | `DataokeService` → 大淘客 API |
| 转链 | `DataokeService.goodsWordVIP()` → `DataokeApi.VIP_GOODS_WORD` |
| 订单查询 | `DataokeService.queryVipList()` → `DataokeApi.VIP_QUERY_ORDER` |

所以**只要配好大淘客就行**：

```yaml
dataoke:
  key: 你的大淘客 AppKey       # admin 第 101 行 / app 第 93 行
  secret: 你的大淘客 AppSecret # admin 第 102 行 / app 第 94 行
```

### 需要额外做的事

1. 在 **大淘客开放平台** <https://open.dataoke.com> 注册并拿到 key/secret。
2. 在大淘客后台**开通唯品会权限**（部分平台权限需要单独申请或有调用量限制）。
3. 在大淘客侧**绑定唯品会推广位**——转链时传的 `adCode`（推广位编码）来自大淘客返回的商品数据，不是本地配置的。如果大淘客侧没绑，转链会返回空。

> 换句话说：**唯品会能不能用，取决于你的大淘客账号权限，不取决于这个项目。**

### 一个额外提醒

大淘客的 key 在 admin 和 app 里**建议用两个不同账号**。配置文件里原本就有这个注释：

```yaml
# todo 大淘客开放平台key和密钥，最好和mshop-app中的不一致，防止订单采集耗空调用量
```

原因：订单采集消耗调用量很大，和客户端查询共用一个账号会互相挤占配额。

## 四、穿山甲：项目没有集成

**穿山甲（Pangle，字节跳动广告平台）在这个项目里完全不存在。**

全项目搜索 `穿山甲` / `pangle` / `csj` / `rewardedvideo` / `bytedance ad`，Java 侧和 Flutter 侧**均为 0 命中**。`app/pubspec.yaml` 里连相关插件都没有（只有一个被注释掉的 `flutter_qq_ads`，那是优量汇，另一家）。

所以它不是一个"配置项"，而是**需要开发的新功能**。如果你要做激励视频广告变现，大致是：

| 端 | 要做什么 | 工作量参考 |
| --- | --- | --- |
| APP（Flutter） | 接入穿山甲 Flutter 插件（社区有 `pangle_flutter` 等），初始化 SDK、加载激励视频、回调上报 | 1~2 天（含真机联调） |
| 服务端 | 新增"广告观看发奖"接口：接收 APP 上报的激励完成回执 → 校验（穿山甲服务端回调验签）→ 发积分/热度 | 1 天 |
| 后台 | 广告位 ID 配置页（可选，也可直接写 yml） | 半天 |

而且需要注意合规：穿山甲要求应用有**软件著作权 + 应用商店上架**才能开通正式广告位，测试阶段只能用测试广告位 ID。

**如果只是想让 APP 有收入入口**，这个项目已经内置了电商返利链路（淘宝/京东/拼多多/唯品会/抖音），不需要广告也能跑通商业模式。穿山甲属于额外叠加，优先级可以放后面。

## 五、改完怎么生效

### 1. 改两份文件

```bash
# 淘宝、京东、大淘客都要在两边同步
server/mshop-admin/src/main/resources/config/application-dev.yml
server/mshop-app/src/main/resources/config/application-dev.yml
```

两个应用的职责不同，缺一不可：
- `mshop-admin`：后台接口 + **订单采集定时任务**
- `mshop-app`：APP 端商品查询、转链、下单

只改 admin → APP 搜不到商品；只改 app → 订单采不进来。

### 2. 重启服务

yml 不是热加载，改完必须重启两个进程（IDEA 里重新 Run，或命令行重启 jar）。

### 3. 验证

**第一步：确认配置读进去了**

看启动日志有没有报配置缺失。如果 `@Value("${tb.appKey}")` 拿不到值，启动会直接失败（`IllegalArgumentException: Could not resolve placeholder`）。

**第二步：后台看平台数据**

登录 `localhost:8013` → 订单管理 → 淘宝/京东/唯品会订单列表，点"采集"或等定时任务跑一轮。

**第三步：抓包看 PID**

APP 端搜一个商品 → 转链 → 复制分享链接，链接里应该出现你自己的 PID（`mm_你的ID_...`）。如果还是 `mm_52650383_...`，说明配置没生效或改错了 profile。

**第四步：看服务端日志**

订单采集失败时日志里会有原始响应，比如：

```
*唯品会订单：{"code":200,...}
```

搜 `唯品会订单` / `淘宝订单保存失败` / `京东订单保存失败` 能直接看到平台返回的错误码。

## 六、配完之后 APP 首页看不到入口？

首页的平台入口有**两个来源**，配 key 只解决"能不能调通"，不解决"有没有入口"：

| 来源 | 位置 | 说明 |
| --- | --- | --- |
| 硬编码菜单 | `app/lib/index/widget/menu_data.dart` | 写死在 APP 里，包含淘宝闪购、9块9、美团红包等入口。**图片地址还指向作者的 alicdn，需要换** |
| 后端下发 | `GET /ku/tiles` → `first_page.dart:192` | 由后台配置，改动无需重新打包 APP |

如果首页没看到某个平台：
1. 先看后台的「商城设置 → 首页装修/菜单」里有没有对应配置（走 tiles）
2. 再去 `menu_data.dart` 里确认是否有硬编码入口
3. 两者都没有，就需要改 APP 代码加一个入口——这已经超出"配置"范畴

> 顺带提醒：`menu_data.dart` 里那些 `img.alicdn.com` 的图片来自作者账号，属于 APP 报告 G1-04 的整改项，配平台 key 时可以一并换成自己的 OSS。

## 七、容易踩的坑

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 改了没生效 | 改的是 `application-prod.yml`，实际跑的是 `dev` | 确认 `application.yml` 里的 `active` 值 |
| 改了没生效 | 只改了一个应用 | admin 和 app 都要改 |
| 转链正常但没订单 | PID 不对，被 `getAdZoneIds()` 白名单过滤 | 核对 `channelPid`/`tljPid` 最后一段数字 |
| 启动报占位符解析失败 | yml 里 key 名拼错或缩进错 | 对比原始文件缩进（两个空格） |
| 淘宝接口报无权限 | 开放平台应用没申请淘宝客类目 | 去开放平台提交权限申请，等审核 |
| 京东转链报错 | siteId 与 unionId 不匹配，或应用未开通接口权限 | 联盟后台核对 |
| 唯品会转链返回空 | 大淘客账号没开通唯品会权限 / 没绑推广位 | 大淘客后台处理 |
| 调用量很快耗尽 | admin 和 app 用了同一个大淘客账号 | 申请两个账号分开用 |

## 八、申请入口汇总

| 平台 | 入口 | 需要准备 |
| --- | --- | --- |
| 淘宝联盟（推广位） | <https://pub.alimama.com> | 实名认证 + 媒体备案（APP 需提供下载链接或备案信息） |
| 淘宝开放平台（AppKey） | <https://open.taobao.com> | 企业/个人开发者认证，申请淘宝客 API 权限 |
| 京东联盟 | <https://union.jd.com> | 实名认证 + 媒体审核 |
| 大淘客 | <https://open.dataoke.com> | 注册即可，部分平台权限需单独申请 |
| 唯品会联盟 | <https://union.vip.com> | **本项目不需要**（走大淘客） |
| 穿山甲 | <https://www.csjplatform.com> | 软著 + 应用上架（本项目未集成，需开发） |

> 这些平台的审核周期通常是 1~3 个工作日，淘宝客 API 权限可能更久。建议提前申请，别等到上线前一天。
