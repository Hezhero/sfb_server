## 联盟平台接入配置指南（淘宝/京东/唯品会/穿山甲）

**任务**：用户本地已跑起 `localhost:8013/dashboard`，问如何添加四个平台的配置。

**核心结论（代码验证）**：
- **四个平台的 API 凭据全部在服务端 yml，后台没有任何页面能改**。`SystemConfigConstants`（数据库 `system_config` 表）里只有 api_url、微信、提现、返利比例等，没有平台 AppKey
- 配置类只有 4 个：`TbConfig` / `JdConfig` / `PddConfig` / `DataokeConfig`，**没有 VipConfig**
- **唯品会无独立配置**：商品/转链/订单三条链路全走大淘客（`DataokeApi.VIP_GOODS_WORD`、`VIP_QUERY_ORDER`），配 `dataoke.key/secret` 即可，但需大淘客侧开通唯品会权限并绑推广位
- **穿山甲完全未集成**：`穿山甲/pangle/csj/rewardedvideo` 在 Java 与 Flutter 两侧 0 命中，pubspec 里只有被注释的 `flutter_qq_ads`（优量汇）。要做需开发（APP 插件 + 服务端发奖 + 合规要求软著与上架）

**参数要点**：
- 淘宝 6 项：`appKey/appSecret`（**淘宝开放平台** open.taobao.com，不是联盟后台）、`url` 固定、`inviterCode`（渠道邀请码，`UserController:337` 用）、`pid.channelPid`/`pid.tljPid`（pub.alimama.com 推广位，格式 `mm_数字_数字_数字`）
- 京东 6 项：`appKey/appSecret`（union.jd.com 开放平台）、`server` 固定、`siteId`（推广位 ID）、`unionId`（联盟 ID）、**`key` 是死配置**（全项目无 `getKey()` 调用）
- `TbConfig.getAdZoneIds()` 取 PID 最后一段数字做订单过滤 → **PID 填错会静默丢单**（表现：转链正常、订单为空）

**关键坑**：默认 profile 是 **dev**（`application.yml: active: dev`），用户跑 8013 前端 dev server + 8001 后端，改 `application-prod.yml` 不生效。两份 yml（admin + app）都要改，缺一个就一边不通。

**行号（dev 与 prod 一致）**：admin — dataoke 100-104 / pdd 137-140 / tb 142-152 / jd 159-166；app — dataoke 92-94 / pdd 128-131 / tb 133-143 / jd 149-156

**APP 首页入口**：两套来源 —— `menu_data.dart` 硬编码（图片指向作者 alicdn）+ 后端 `/ku/tiles` 下发（`first_page.dart:192`）。配 key 不解决入口问题。

**产出**：`docs/04-联盟平台接入配置指南.md`（8 节，含速查表、申请入口、验证四步、常见坑表）
