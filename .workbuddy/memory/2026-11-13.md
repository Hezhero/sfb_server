## CPS 转链分销指南（零考核版）

按用户要求重出：只做转链拿佣金，不参与任何 API 考核。产出 `docs/07-CPS转链分销指南-零考核版.md`（旧的小微企业 API 版已删，无其他文档引用）。

**核心论断**（代码实证）：
- **入驻 ≠ 备案 ≠ 考核**，三者要分清。备案必须做（否则转链无效/佣金失效），考核只卡 API 高级权限
- 唯一有佣金考核的是**穿山甲电商联盟 API**（首月日均>1000），绕开它用大淘客的抖音通道即可零考核
- 淘宝的订单查询 API 是邀约制（返利类可能拿不到），但**转链没考核**，订单可用大淘客 `queryTBList` 中转

**关键发现——大淘客一个账号覆盖 5 个平台**：
`DataokeService` 有 `queryTBList` / `queryJdList` / `queryPddList` / `queryVipList` / `queryDyList`
好单库（`KuService`）补饿了么（`eleOrder`）+ 抖音生活
采集任务类：`DyOrderCollectionTask`（抖音）、`JdOrderCollectionTask`、`PddOrderCollectionTask`、`OrderMtCPSCollectionTask`（美团）、`EleKuOrderCollectionTask`（饿了么）、`CsjEcomOrderCollectionTask`（穿山甲）

**注意点**：拼多多订单实际走**官方** `PddService.queryPddOrderList`，大淘客 `queryPddList` 只是备用（第一版文档写错，已修正）

**零考核路线**：拼多多/京东（当天）→ 淘宝（备案1-3天）→ 大淘客+好单库（3-5天接进系统）→ 唯品会/抖音 → 美团（需执照）

## 全平台接入指南（小微企业版）

产出 `docs/07-全平台接入指南-小微企业版.md`（351 行）。

**代码实证的支持矩阵**（7 个平台）：
- 订单表：`mw_order_tb/jd/pdd/dy/vip/mt/ele`
- 配置块：`tb` `jd` `pdd` `ele` `meituan` `dataoke` `haodanku` `csj` `csj-ecom`
- **不支持**：快手、小红书、淘特（全项目 0 命中）

**关键发现**：
- `tb.appKey`（xxxx3230）与 `ele.appKey`（34xxxx21）**是两个不同的值** → 饿了么走同一网关 `eco.taobao.com/router/rest` 但用**独立 AppKey**，不是复用淘宝的（第一版文档写错，已修正）
- 唯品会无独立配置，商品/转链/订单全走大淘客
- 淘宝 API 分两档：基础权限（商品/转链）可申请；**高级权限（订单查询、万能转链）邀约制，且排除"返利类、入口类渠道"** → 返利 APP 可能拿不到淘宝订单 API（此条来自行业资料，非官方原文，已在文档标注）

**小微企业结论**：有个体户执照 = 7 平台全通；纯个人只能做淘宝/京东/拼多多/唯品会（美团明确不支持个人，抖音穿山甲要求企业或个体户）。

**三梯队**：① 当天开通（拼多多/京东/淘宝/唯品会）② 需执照+备案（美团/饿了么）③ 需考核（抖音穿山甲，首月日均佣金>1000）

**推荐路线**：拼多多 → 京东 → 办个体户 → 淘宝 → 唯品会 → 美团 → 抖音
