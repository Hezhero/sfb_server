## 穿山甲电商联盟（抖音电商 CPS）接入

**任务**：用户要"接入穿山甲的电商联盟"。先查证：**穿山甲电商联盟确实存在**，原名「乘风计划」/「抖客」，本质是**抖音电商 CPS 分销**，不是新电商平台 —— 与项目现有抖音模块同一货源、不同通道（大淘客 vs 字节官方直连）。

**接口协议（28733）**：
- 网关 `https://ecom.pangolin-sdk-toutiao.com`，POST，application/json
- 封包：`app_id` / `data`(紧凑JSON字符串) / `req_id`(UUID) / `sign_type`="MD5" / `timestamp`(秒) / `version`="1" / `sign`
- **签名**：`MD5("app_id=..&data=..&req_id=..&timestamp=.." + secureKey)`，32位小写
- **两个坑**：① `version`/`sign_type`/`sign` **不参与加签**，拼进去报 `100004 sign check fail`；② `data` 必须是紧凑 JSON，且签名与发送复用同一个字符串
- 接口：`/order/search`、`/product/search`（page_size 1~20，超限报 100002）、`/product/link`

**权限门槛（关键，已写进文档）**：
- 主体：企业法人或个体工商户 + 实名 + 对公账户小额打款验证
- 流程：签合同 → 合规考试 → **流量备案**
- **`/product/search` 和 `/product/link` 未备案直接返回 `{"code":100011,"desc":"暂无业务权限"}`**；`/order/search` 门槛低
- 备案方式：应用市场上架链接+包名+截图，或《媒体流量备案登记表》人工审核
- 后续 V1~V4 等级考核（月GMV/退款率≤40%/推广管理分≥10），不达标可能取消权限

**代码改动**：
- `mshop-store/.../csj/config/CsjEcomConfig.java`、`service/CsjEcomSigner.java`、`CsjEcomClient.java`、`CsjEcomOrderService.java`
- `mshop-admin/.../quartz/task/CsjEcomOrderCollectionTask.java`
- `mshop-app/.../csj/rest/CsjEcomController.java`（`GET /csj/ecom/products` 匿名、`POST /csj/ecom/link` 需登录）
- 4 份 yml 加 `csj-ecom` 块（**admin 也要配，订单采集跑在 admin**）

**关键复用**：订单直接落 `mw_order_dy`，穿山甲 `flow_point` 与大淘客值域完全一致（PAY_SUCC/CONFIRM/SETTLE/REFUND），现有分佣/状态/APP 列表全不用改。转链 `custom_info` 必须写成 `csj_{uid}_{随机}` —— `OrderUtil.getDyOrderUser()` 按下划线取第二段作 uid。

**幂等坑**：`MailvorDyOrder` 实体**没有 id 字段**，不能直接 `saveOrUpdateBatch`（会重复插入）。改为按 `order_id` 查存在性：不存在 save，存在只 update 状态字段（不碰 uid/bind/hb）。

**踩坑记录**：javadoc 里写 cron `0 */10 * * * ?` 时，`*/` 会**提前闭合注释**，导致"需要 class/interface/enum"编译错误 —— 改成 `0 0/10 * * * ?` 或放进 code block 之外的描述里。

**验证**：编译 BUILD SUCCESS；签名用 Python 独立计算比对逐字节一致（`e95395e1a59ad40875e305cf9ab1d82d`）；封包字段与紧凑 JSON 均正确。**接口实际调用未验证**（无 appId/secureKey、无备案）。字段名按公开文档实现并做多候选容错，联调时需对照真实返回校正。
