## sfb_server（苏分宝淘客系统开源版）安全审计 + 授权分析 + 部署文档

**任务**：分析项目、排查后门、商用授权规避、输出部署配置文档。

**结论**：无恶意后门（命令执行/反序列化/隐藏账号/数据回传全部为 0），但有 6 类"等同后门"的硬编码默认值。

**关键发现（含行号，后续复用）**：
- P0 APP端 JWT 密钥硬编码 `mshopmini`（`mshop-app/.../application-prod.yml:68`），`JwtToken` HMAC256 + `UserInterceptor` 仅验签 → 可伪造任意 uid
- P0 淘客 PID 全是作者的：`mm_52650383_39582271_114587650437` / `tljPid mm_52650383_3088500089_115682150104`（prod.yml:150,152）、`pdd.pid 1784892_252288888`
- P0 Druid `admin/123456`（prod.yml:40-41）+ `SecurityConfig.java:123` `/druid/**` permitAll
- P1 `jwt.base64-secret` HS512 硬编码（prod.yml:72），`jwt.secret` 实际未使用
- P1 RSA 私钥 / AES key 硬编码（application.yml:46,49）
- P1 CORS `addAllowedOriginPattern("*")` + allowCredentials（ConfigurerAdapter.java:41-43）
- 授权地雷：**iText 5.5.13.3 = AGPL**（mshop-system/pom.xml:78），仅 `WordUtil.java` 引用 → 可用 OpenPDF 替换；**aspose-words 18.6** 商业库，由 `shop.convertContract`（默认 false）控制
- LICENSE 2.1「自用可盈利不受限制」vs README「商用须付费」冲突 → 自营属自用免费，对外交付/多租户需商业授权

**部署要点**：
- admin 8001/admin，app 8008/api；默认 profile 是 **dev**（README 说 prod，与代码不符）
- Quartz 用 RAMJobStore，任务由数据库 `quartz_job` 表驱动，**不需要 QRTZ_\* 表**
- 实际用 lettuce，`spring.redis.jedis.pool.*` 不生效
- `mshop.apiUrl` 是死配置，真实地址在 `system_config.api_url`
- `file.avatar: /homemshop/avatar/` 是笔误（少斜杠）
- `jwt.token-validity-in-seconds` 实际按毫秒用
- 构建实测：`mvn -pl mshop-admin,mshop-app -am package -DskipTests` → BUILD SUCCESS 58s，jar 157M/159M，system scope 已打入
